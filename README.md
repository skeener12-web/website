# Sabrina's Hobbies
A responsive HTML, CSS and JavaScript hobby portfolio inspired by a Canva mockup.

## Run locally
Open `index.html` in your browser or use VS Code Live Server.

## Publish
Create a public GitHub repository, upload `index.html`, `style.css`, and `script.js`, then open Settings > Pages > Deploy from a branch > main > /(root) > Save. GitHub will display your published URL when deployment completes.

## Self review
- Clear navigation and descriptive headings
- Responsive layout for phones and desktop
- Page title, description, and accessible button labels
- Six interactive hobby cards
- Required form fields and validation
- Contact form is a demo until you configure a recipient in `script.js`; it uses the visitor's email application and does not store messages.

Replace the emoji artwork with your own exported Canva assets later if you want a closer visual match. Do not upload the phone screenshot as a site graphic; it is included only as a reference.

## Personal images
The `images` folder contains the provided Canva hobby artwork and portrait. The hobby cards show the full original images and scroll to their descriptions when selected.

## Updated content
